Solmar City is an original open-world crime game: Rio Vega explores a 6-district city on foot and by car, steals rides, outruns the police through a 5-star wanted system, and fights through 8 missions to bring down BIG MARCO. 100% offline — plain HTML, canvas and JavaScript, no assets from the internet.

## Run it
```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 in a desktop browser
# (or just open game/index.html directly — it also works from file://)
```
